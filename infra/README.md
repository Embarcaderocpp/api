# Инфраструктуру собираешь ты

На этапе 1 создай здесь `compose.yml` для PostgreSQL либо используй локальную установку.
Compose, Dockerfile приложения и настройки БД намеренно не предоставлены.

Критерии:

- Версия образа PostgreSQL зафиксирована, не `latest`.
- Есть отдельные БД и пользователь приложения.
- Пароль приходит из окружения, в Git есть только `.env.example` с примерами.
- Данные переживают перезапуск контейнера.
- Есть healthcheck; порт БД при локальной разработке опубликован только на loopback.
- Команды запуска и остановки записаны в README проекта.
- Ты понимаешь, какая команда удаляет данные, и не используешь её для обычной остановки.

После этого: контейнеризация приложения и CI — этап 7.
`server.address` в готовом каркасе настроен на loopback. При контейнеризации
приложения продумай переопределение адреса и публикацию порта.
